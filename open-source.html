A SHARED FOUNDATION

Four products.
Without four copies of the code.

Nexum and Nexum FX build their effect modules from one implementation. A shared UI library keeps the family visually connected. Tune and Gate complement them as independent audio effects.

├─ Nexum/ Synthesizer + FX

├─ NexumTune/ Pitch & Timing

├─ NexumGate/ Shaper · Gate · Pan

├─ NexumDesign/ Shared UI

└─ external/JUCE/ Framework

BUILD IT YOURSELF

The source is included.
Bring your own tools.

What you need

Windows x64, Visual Studio 2022 with Desktop development with C++, and CMake 3.22 or newer. Source archives include JUCE and the other required libraries.

What's in the archive

Product source, assets, shared UI components, tests, build files and full license notices. Configure each project in its own build directory.

EXAMPLE / NEXUM + FX
cmake -S Nexum -B build-synth   -G "Visual Studio 17 2022" -A x64

cmake --build build-synth   --config Release   --target NexumSynth_VST3 NexumFx_VST3   --parallel 1

Full PowerShell build commands for all four products are included in the source archive's README.
