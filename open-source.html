A SHARED FOUNDATION

Five products.
A shared foundation.

Nexum and Nexum FX share their synthesis and effects repository. Tune, Gate and Rec pin the same shared UI and JUCE source through a submodule. Each product has its own repository under nexum-audio.

BUILD IT YOURSELF

The source is included.
Bring your own tools.

Clone with dependencies

Use git clone --recurse-submodules for the companion repositories. The full suite source ZIP includes the shared core once, plus all five product trees and build instructions.

Build on Windows

Visual Studio 2022 with C++ desktop development, CMake 3.22+ and Windows x64. Keep builds at one worker on memory-constrained machines.

EXAMPLE / NEXUM + FX
git clone --recurse-submodules https://github.com/nexum-audio/nexum.git
cmake -S nexum -B build-synth -G "Visual Studio 17 2022" -A x64
cmake --build build-synth --config Release --target NexumSynth_VST3 NexumFx_VST3 --parallel 1

The complete source archive includes separate build commands for Tune, Gate and Rec. The archive README explains how to point companions to the included shared core.
