Nexum FX
Modular effect rack

01

17 modules. One shared engine.

Nexum and Nexum FX build their rack effects from the same implementation. Choose Bode, Chorus, Compressor, Convolve, Delay, Distortion, Equalizer, Filter, Flanger, Hyper / Dimension, Phaser, Reverb, three Splitters, Utility and Trancegate.

02

Build the chain in plain sight.

Add effects to the Main rack, change their order and control each module from its rack rail. The list stays on the left, with remove and bypass controls beside each effect. A coloured bypass icon means the effect is bypassed.

03

One library for two plugins.

Save individual effects and complete chains with metadata, tags, categories and ratings. The shared FX Library makes these rack settings available in both Nexum and Nexum FX.

04

Space, movement and pulse.

Load an impulse response into Convolve, sculpt tone with distortion, EQ and filtering, or introduce motion with modulation and delay. Trancegate adds a programmable rhythmic gate inside the same rack.

05

A header built for the session.

Navigate presets from the common header or the PRESETS page. Global Mix, Master, bypass and adjacent L/R meters stay together at the top, with the blue Nexum FX accent.

06

Macros for the whole chain.

Link continuous controls to growable macros and save their ranges with the preset or project. The first eight macros are available to host automation. Mono and stereo audio inputs are supported.

Nexum FX is an audio effect with one Main rack. It does not contain synthesis oscillators or the synth’s Bus 1 / Bus 2 routing. In the standalone, select an audio input and enable input monitoring when needed.

Install in three steps.

  1. Extract

    Download the Windows ZIP and extract it into its own folder.

  2. Copy the VST3

    Copy the entire Nexum FX.vst3 folder to C:\Program Files\Common Files\VST3\NEXUM.

  3. Scan for plugins

    Run a fresh plugin scan in your DAW and load Nexum FX as an audio effect. The EXE in the ZIP opens the standalone.
